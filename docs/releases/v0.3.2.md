# FactCircuit v0.3.2

This release makes the first installation and complete offline example
reproducible. FactCircuit remains a research preview; the model-backed semantic
adapter is experimental.

- Added `factcircuit quickstart --output DIRECTORY`, which writes a readable
  summary, frozen inputs, resource config and full provenance trace.
- Added explicit budget configuration and existing-output protection.
- Added `factcircuit --version` and retained the `newsverify` compatibility CLI.
- Documented macOS/Linux and Windows installation, expected results, configuration,
  troubleshooting, and a minimal custom-claim local model input.
- Included the previously developed archived-response replay and local GGUF
  inference workflows. The provided GGUF setup selects Qwen, not Astra.
- Added isolated wheel installation checks outside the checkout, with first-run
  CI coverage on Linux, macOS and Windows.

Start with the [installation guide](https://github.com/superwesleyhys-ux/factcircuit/blob/v0.3.2/docs/QUICKSTART.md).
Source archives include experiments and setup scripts. The wheel contains the
offline core CLI and adapter API. Downloaded weights and local configurations
are not distributed.

The offline example uses fictional evidence and hand-authored annotations.
The release checks do not generate fresh model responses or establish accuracy.
The earlier two-case Astra comparison and its known full-evidence diagnostic
failure remain documented in the repository. This release does not claim a fix
for that experimental semantic error or a new model-performance improvement.
