# 第五版策略测试：Astra 与 harness

**结果持平，尚未超过原始 Astra。** 8 个虚构机制案例（4 组配对）中，原始 Astra 与第五版 harness 均有 8/8 个答案匹配事先冻结的标准答案，且全部通过独立证据审阅。此轮实际调用了 Astra，但案例是虚构材料，不能视为真实历史新闻造假检出率的提升。

| 指标 | 原始 Astra | 第五版 harness |
| --- | ---: | ---: |
| 预登记案例 | 8 | 8 |
| 完成且通过流程检查 | 8 | 8 |
| 标准答案匹配且证据支持 | 8/8 | 8/8 |
| 真实模型调用 | 8 | 88 |
| 成功调用 | 8 | 88 |
| 已记录 token | 79,845 | 1,049,311 |
| 真命题对照被误判为假 | 0/2 | 0/2 |

本轮实质改变了判断流程：保留原有溯源初判后，让一个看不到初判的新审查步骤完整检查同一份可用证据，提出可核验的反对理由；最后单独裁决每项理由。没有反对理由可以直接返回空列表。原始出处的身份、缺少独立佐证或“看起来可疑”本身均不能自动判假。

同一轮 harness 的前序初判匹配 7/8，新增步骤后最终匹配 8/8，有一项改判。这只是同一流水线内部的诊断，前序结果不是独立重跑的第三版对照；最终改判已通过盲审。随后进行的非盲诊断发现：初判只核验了其中一份记录，并把已经提供的竞争记录当作缺失；新增步骤重新检查完整材料后，保留了同一范围内真实存在的证据冲突。单个案例无法区分改进来自隐藏初判、完整证据暴露、额外调用还是最终裁决。原始 Astra 已经是 8/8，所以该变化不构成超越原始 Astra。

两组使用同一 Astra 模型、medium 推理等级和本地 Codex 登录路线。这里的本地指调用路线，模型推理仍由远端服务完成。两组收到同一案例的完整可用材料，基线策略保持原样。96 次逻辑模型调用全部成功，共记录 1,129,156 token；不含本次工作中的编排和独立审阅用量，内部 CLI 重试未另行计数。token 只记录，未用于选择胜出方案。

新真实新闻的溯源另外完成了 12 次有预先记录的检索或获取操作；每次均按最新缺口重新分解提示词。独立准入核验没有找到新的、符合“2024 年之前发生且于 2025–2026 年被证实为假”的精确命题。修正通知涉及目标年度和项目，但未给出足以证明原始显示数字改变的年度调整额；同一候选的完整材料还超过预设容量。未放宽准入条件，也未截断证据凑出测试案例。

本轮策略、输入、评分和调用记录已按登记执行。第一次启动准备因路径形式出错，在模型调度之前结束，保留了零调用的失败记录；修正调用路径后完成了唯一一次模型试验。未重新运行任何推理行。当前策略的单次执行标记已使用，下轮必须有可解释的决策行为变化、独立审阅和新登记，不能只改措辞或输出目录重复抽样。旧结果保留，所有预登记案例均纳入分母。

独立代理在隐藏组别、标准答案和映射的条件下审阅并冻结全部 16 个结论，之后再关联组别与评分；43 处最终引用与 52 处审阅证据均能精确定位，未发现实质推论错误。这是 AI 代理审阅，并非人工裁定；审阅者曾接触通用代码和机械桩测试，文字风格也可能影响盲法。调用完整性另经独立核验，96 份完整事件记录均与最终输出和用量对应，无截断、未知用量或工具执行记录。

本轮没有剩余的最终判断错误可据以声称新的修复目标。下一轮须先找到新的可检验弱点，实质改变策略，再预先登记完整测试；本批案例从此属于已见开发材料。真实新闻优势尚未成立；准确率目标未达到。
