总计 21 次真实调用，全部成功，647,564 tokens。harness 使用约 8.24 倍 token，本轮没有观察到准确率增益。token 仍只记录，未做压缩或优化。统计不含资料搜集、协调和独立审阅开销；模型服务内部重试未单独计量。

## 没成功的具体部分

没有解决“原始来源所述事实后来被纠正时，如何用当时材料提前发现”的问题。找到原始来源、引用准确、推论符合当时证据，都不保证来源所述事实最终为真。本轮两种方式均给出支持；不能把证据判断的 2/2 说成提前识假的 100%。

独立复核没有发现四个最终答案的实质推论或目标范围错误。因此不能把这轮归因为传输失败或随便挑一句提示词，声称已经找到造成漏检的原因。新增诊断在 21 次调用中完整记录了原始输出；它改善可诊断性，没有证明提高识假能力，也不能补回旧失败调用已丢失的细节。

执行记录显示，一条 harness 流程发生一次核验反馈；两条均未执行重新分析与两个循环的完整组合。不能仅凭多次核验就宣称“双循环完整执行”。harness 中 token 最多的阶段为核验 103,951（18.00%），随后为来源追踪 92,980（16.10%）和证据分解 80,181（13.88%）。

## 本轮怎么测试

两边采用相同 gpt-6-astra、medium 推理、本地 Codex 登录 HTTP 路线；模型推理仍在远程完成。原始 Astra 对照使用相同 CLI 环境。两边能访问相同冻结的历史资料池，harness 可按自身流程选择材料。安装的技能目录与模型工具被禁用；没有外部溯源请求或 API 路线回退。harness 使用本轮事先冻结的 Candidate 3，未提升没有实证优势的 Candidate 4。

两条记录来自两个新独立事件，事件和输入证据截止到 2023-12-31。后来被纠正项满足 2025–2026 年的正式确认与首次公开年份条件；确切首次公开日期仍未知，保留年份和公开记录上界，不虚构精确日期或闭合区间。该项是狭义事实纠正，不代表整个故事或蓄意造假。过滤输入无法消除模型预训练记忆。

四组顺序和全部分母在调用前固定。实际请求通过审计并保存审计文件之后才读取后来标签。四个最终答案按隐藏条件名的记录独立核验，十处模型引用和十七处审阅证据跨度全部核实。审阅者此前见过截止资料，这项接触已披露；没有声称完全盲测。两条案例仅是诊断样本，不能外推为普遍正确率。

用户新增“每次修改策略，不要反复跑同一套”要求后，没有启动任何新模型测试。本轮调用在该指令前已经全部完成，旧结果完整保留。
