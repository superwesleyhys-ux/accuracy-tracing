# 新版指导词对照测试：尚未超过原始 Astra

**本轮没有证明新版 harness 更准。** 14 个合成案例各运行原始 Astra、旧版 harness（Candidate 3）和新版 harness（Candidate 4），共 42 项。使用真实 Astra 调用；案例内容是虚构的证据推理对照，不能当作真实新闻识假成绩。

| 结果 | 原始 Astra | 旧版 harness | 新版 harness |
| --- | ---: | ---: | ---: |
| 全部计划案例 | 14 | 14 | 14 |
| 结论和理由均合格，按完整分母计分 | 14/14 | 12/14 | 12/14 |
| 缺少最终答案的案例 | 0 | 2 | 2 |
| 已完成答案中的实质推理错误 | 0/14 | 0/12 | 0/12 |
| 应接受的正向对照得到正确支持 | 6/6 | 6/6 | 6/6 |
| 应被反例或计算反驳的案例完成正确反驳 | 2/2 | 1/2 | 1/2 |
| 应保持未解决的案例完成正确判断 | 6/6 | 5/6 | 5/6 |

独立审阅在隐藏组名的情况下先固定全部 42 项判断，之后才揭示组别。38 个最终答案的结论与证据关系均合格；另外 4 项缺失答案，不能把它们解释为弃答、错误推理或成功识假。审阅核对了 74 处模型引文和 81 处审阅证据片段。审阅者看过通用协议和评分代码，回答措辞也可能暴露组别，因此不声称完全盲审。

## 具体未成功的部分

两个 harness 都在 s13、s14 缺少最终答案。这对案例检查“范围内的反例能否推翻主张”和“范围外的类似记录不能作为反例”。原始 Astra 完成了这两例。

全批记录到 **190 次调用尝试，182 次成功、8 次失败**。失败包括 5 次按程序计时约 90 秒的本地调用超时，以及 3 次本地调用虽然进程退出码为 0、但模型回合失败或未完成。后 3 次仍保留了用量；前 5 次用量未知。当前传输层没有保留完整事件流和错误输出，无法进一步确认是提供方还是本地客户端导致。四项失败的 harness 结果还存在 UTC 时间间隔与程序计时不一致，原因未确认；不能把程序计时直接当作完整的现实经过时间。

所有失败都保留在原始记录和完整分母中；没有只重跑失败案例。本轮新增的“证据角色必须有根据”指导词，在两版共同完成的 12 个案例上没有减少推理错误。最后一对对照未在 harness 中完成，因此也不能声称 harness 已通过全部 14 个案例。

两版均未记录到接受后重新查证、重新分析或双循环完整执行。核验阶段虽然各有 18 次调用尝试，但这不等于两个循环都执行了。新版指导词未达到本轮推进标准，未安装为生产默认方案。

## 真实新闻资料的进展

另行完成 20 次来源检索和 2 次针对早期官方公告的补查。每次外部操作前都重新分解并保存目标、现有证据、查询、验收条件、停止条件和上次返回导致的调整。失败和未用完的预算均保留；文件观察与本地记录不被表述为网络层的完整拦截证明。

两个新事件来源通过独立准入，其中一个具体主张后来被证伪，另一个是真实事件对照。它们未进入本轮合成测试，也尚未进行新的模型比较。后来的首次公开证伪年份和正式结论年份满足既定 2025–2026 年要求；最早公开的精确日期仍有已记录的范围不确定性。来源版本采用保留的文件及对应关系核验，没有声称取得历史加密快照或证明互联网上绝不存在更早信息。

新找到的截止日期前官方记录已加入另一份冻结材料版本，原来的主张、材料、顺序和对照保持不变。这个最终版本已由另一位未看过该案例先前标签及后来结论的审阅者完成截止期判断：两条具体主张都被当时的材料支持，18 处原始证据位置核验通过。原始包和先前判断没有被覆盖。这位审阅者此后不再为这些事件调整指导词，主协调者继续保持真实来源盲态。最终标签和准入交接已经单独封存，新的执行器适配与模型注册尚未完成。评分数据保留了首次公开日期的不确定性，没有为了适配旧执行器而编造精确日期或把新案例标为已暴露。

## 测试边界和后续工作

三组使用相同的 hosted gpt-6-astra、medium 推理及本地 Codex 登录通道。本地指调用通道，模型权重仍在远程。输入材料相同，关闭来源网络和安装的技能目录，没有 API 回退。截止日期后的调查记录和评分标签没有提供给测试模型；模型已有知识并未被抹除。

运行前固定了指导词、材料、标签、代码、顺序和调用上限。实际请求核验先于评分读取标签；随后才进行隐藏组名的语义审阅和组别连接。独立完整性审阅核对了 864 个结果文件、190 次请求及 64 次指导词应用，组别连接也独立复核通过。测试运行内的 17 次搜索只访问冻结的本地材料，没有新的外部来源请求。旧版预备执行器的截止时间记账问题在真实调用前已修复并单独保留，新版按注册版本运行。

下一步优先补齐失败调用的诊断，再按独立冻结的最终真实新闻材料设计下一轮完整对照。当前没有证据支持继续堆叠提示词或只重复已经做对的案例。持续目标仍未达到；本报告不宣称已超过原始 Astra。
