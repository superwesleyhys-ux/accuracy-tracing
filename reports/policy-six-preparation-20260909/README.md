# 第六版：先完整读取来源，再开始判断

**策略已经实质修改并通过本地验证；尚未证明超过原始 Astra。** 本次没有重复运行第五版，也没有把本地程序测试算成新闻识假成绩。准确率仍是目标，token 只记录。

| 环节 | 第五版的初步判断流程 | 第六版 |
|---|---|---|
| 来源进入分析 | 先读一份；可能在其他已提供资料被分析前结束 | 第一批纳入全部符合条件的原始资料 |
| 开始判断的条件 | 已读取资料可能足以触发判断 | 每份原文都完成分解，才允许判断 |
| 缺失、改动或未分析的资料 | 可能造成初步判断遗漏 | 阻止该次判断，保留明确失败 |
| 完成证明 | 依赖原有流程记录 | 重放实际保存的分析和判断记录，核对输入、顺序及资料内容 |

原始 Astra 对照组、第五版最后两步复核、模型、推理档位和调用上限保持原配置。第六版不增加一个模型阶段。它修复的是初步判断提前结束的机制；第五版的最后复核已修正此前观察到的那一处遗漏，因此不能声称第五版最终答案仍存在同一错误。

本地集成测试 **47/47** 通过，独立实现与重放检查 **16/16** 通过。检查覆盖完整读取、缺失或被改动的原文、未完成分解、目标被改动、伪造记录和失败后状态恢复。独立检查发现的目标引用问题已修复，最初失败记录保留。47 项执行结果来自本次工具记录；没有另外保存完整原始日志。代码与验证材料已锁定，55 个文件的内容校验通过。这些都是程序行为验证。

真实新闻材料仍有缺口。本次完成 **24 次来源请求**，每次请求前重新分解并保存检索提示。独立核验得到一条肯定性对照、一条仍待确认首次公开证实时间的更正事实候选；目前各只有一份可用原文，不能检验本次多来源策略。另有一份完整年报超过当前输入上限，未截短使用。论文原图恢复的四次请求均未取得原文、图像或附件；两个 HTTP 成功响应实际只是主页与位置元数据，未计为成功恢复。**新增可运行的真实真假配对为 0，第六版新闻模型调用为 0。**

本地图片通道的单次测试成功：同一 Astra / medium 配置正确读出人工图片的数字和颜色顺序，耗时 5.34 秒，使用 9,103 输入 + 55 输出 = **9,158 tokens**。图像在调用前锁定，预期答案在保存请求和回执后才用于评分；未重复调用。它仅说明这条路径能使用这张图片，不证明论文图像鉴伪能力或新闻准确率。独立核验已通过，具体回执与能力边界见 VISUAL-PROBE.json。现有第六版仍使用文本资料；图像接入和图中区域证据记录尚需实现。

此前成绩保持不变：第五版在八道人工测试题中与原始 Astra 同为 8/8；最近真实历史新闻诊断中，两者均未识别出那一条后来被证实为假的目标。不能据此宣布超过。下一次新闻测试需使用完整、符合时间条件且能实际触发新策略的材料，提前锁定全部用例和评分规则；每轮保留失败、完整分母和旧结果。
