# C7 真实历史图文测试：原始 Astra 与 harness

**本轮没有超过原始 Astra。** 两组都没有有依据地识别出那条后来被判假的命题，结果均为 **0/1**。新版 harness 完成了图像比较，但把相似现象升级成了缺乏充分依据的“证据冲突”。这是需要修正的具体判定环节。

这次确实运行了新策略，并非重复旧提示词。C7 在完整文字溯源之后，用“独立图像比较 → 对照原图裁决”替换原来的两步复核。它同时包含此前尚未实测的 C6 完整文字准入；本轮只能评价这个组合，不能单独归因于图像功能。文字对照题沿用 C6 流程。

**真实调用结果**

两条独立真实事件、四组结果全部完成，22 次本地模型调用（按 CLI 调用记录计）全部成功，用时约 6 分 11 秒。两组均使用 gpt-6-astra、medium 推理、本地 Codex 登录 HTTP 路线。这里的“本地”是调用路线，模型推理仍在远端。测试使用冻结的历史资料池，运行时没有联网补充新闻。

图文题包含完整的 13 页原始正文图页。原始 Astra、harness 的图像比较与图像裁决三次调用，实际携带了相同顺序、相同字节的全部 13 页；其余 19 次文字调用没有图片。模型工具和已安装技能目录均被禁用。输入、调用、图片与返回记录已完成核验。

**评分分歧必须保留。** 预先冻结的截止期标签把争议命题判为“无法确认”；新加入、未接触条件映射或后续结论的独立复核者认为，原始直接记述及图示足以提供初步支持。原评分者随后在不看模型结果的情况下澄清：其原判断采用了更强的“追溯到实际采集过程”的核验门槛，而题目并未明确要求独立认证的原始记录。金标准、模型答案和复核判断均保持原样。这使截止期分数对证据门槛敏感，不宜把其中一个百分比包装成稳定的真实正确率；两种评分口径都没有显示 harness 胜出。

**具体没成功的地方**

- harness 从图像的相似特征推断出实质冲突，却没有证明这些特征在来源所述条件下不能同时出现。定位到原图、给出有效坐标，不等于证明了归属错误。
- 原始 Astra 对同一命题选择了“无法确认”。独立复核认为它要求了题目未明确规定的额外真实性认证；原冻结标准则接受这个保留判断。这里首先要明确证据门槛，不能为了得到更高分而事后改标签。
- 本轮确实取得并传入了完整原文图页，但仍未增加对后来错误命题的有依据检出。拒绝确认、报告疑点或报告冲突，都不等同于已经判假。

下一版应优先加入“冲突成立条件”的检查：分别写出每条证据直接支持的命题，核对对象、条件与时间范围，并说明为什么两条命题不能同时成立。只有相似现象或原始记录缺失时，应回到完整证据判断，不能自动升级为冲突。同时在下一次登记前明确“作者报告了什么”和“实际来源已经得到何种程度核验”的区别。这个后续方案尚未作为新一轮策略运行。

已保留的 5 张较早比较图与 2024 年评论关联，仍超出本次截止线；找到的 1 条截止期内质疑针对另一部分，不能直接证明当前命题为假。

资料截止到 2023-12-31；后来确认错误的依据留在评分侧，未进入模型输入。更早的公开质疑与后来确立的结论已分别核对，但不宣称穷尽了全球所有更早披露。过滤输入无法删除 Astra 的训练记忆。样本是有目的选取的两条事件，文字对照也没有检验“合法复用图像”的识别能力，因此本轮不能代表普遍新闻准确率。
