# 逐次提示词拆解：实测验收清单

本清单用于独立审计与报告，依据 `SOURCE-PROMPT-DECOMPOSITION.md`、`NEXT-SOURCE-PROMPT-0712.md` 和公共 STATE 的安全状态制定。它不是新增审批关卡，不要求已获授权的取件逐次等待确认，也不证明任何案例已准入或准确率已提高。

| 检查项 | 可以验收的实际记录 | 不能单独作为证明 |
|---|---|---|
| 本轮确实重新拆解 | 新轮次的完整计划引用上一轮实际返回和未解决缺口，写明目标、证据、路线、检查、停止条件及变化理由；计划先保存，其哈希进入本轮登记，随后才有首个外部动作。 | 只有新的文件名、不同措辞，或事后补写的“执行前已计划”。 |
| 每次主动操作前都有子提示词 | 每项主动搜索、取件、显式重试均有独立尝试 ID；动作开始前已保存当前缺口、精确范围、实际请求、验收条件、反证、后续分支、证据用途、父计划/规则哈希和剩余预算。批量请求逐项记录。 | 仅有整轮总提示词，或一次下载后补出多份子提示词。 |
| 保存顺序可以交叉核对 | 预先保存的计划/子提示词哈希，与登记记录、执行序列、实际工具调用或请求回执相互对应；首次调用前的承诺及每次调用前的保存有可查记录。单独的自填时间或文件修改时间不足时，标记“顺序证据不足”。 | 自报时间戳、最终一次性生成的清单、仅有结束后的文件哈希。哈希证明字节一致，不能自行证明创建先后。 |
| 请求与返回真正绑定 | 尝试 ID 唯一，实际发出的查询/URL/参数与已保存子提示词相符；私有记录绑定请求及实际返回的哈希、错误、可见跳转、完成状态和证据类型。失败、空结果、外壳、元数据也保留，不能漏掉。 | 总操作数、成功次数或一句“查过了”，没有逐项请求与返回。不能用另一条请求的成功返回替换原尝试。 |
| 下一次拆解依据真实返回 | 新子提示词明确引用已完成返回的 ID/哈希，说明哪项信息改变了路线、检查或停止决定，并指向具体缺口。首项可引用上一轮；并行项只能引用启动前已知材料。没有新信息或新路线时停止。 | 只换同义词、重复已耗尽端点、编造尚未发生的并行返回，或为了更容易判假而调整目标。 |
| 预算没有随拆解重置 | 同一轮累计主动操作和用时，包含明确重试；逐项预算与实际请求数、开始/结束记录对齐。本次草案边界为同一既有事件、最多 12 次外部操作、15 分钟，先到即止。自动重定向/传输内部重试按登记口径记录可见部分，不递归要求新提示词，不声称掌握不可见内部动作。 | 每份子提示词重新领取全部预算；只统计成功动作；改写提示词后继续超额操作。 |
| 既有记录未被改写 | 已执行计划和子提示词的最终字节仍匹配执行前绑定哈希；结果以追加记录或独立返回记录保存。新方向生成新尝试，超出原轮范围则保留旧轮并另行登记。 | 覆盖失败提示词、删除不利返回，或把事后已知信息写进先前版本。 |
| 没有重复执行者 | 私有 PASS-STATE 的轮次/执行者/当前尝试/动作状态与公共安全指针一致；恢复前核对活跃执行者和未完成请求。无法确定是否已发出时标记不明并核对，不自动重发。核对实际调用记录中没有同一计划动作的重复消耗。 | 单独一个 owner 字段、一次状态更新，或声称存在尚未实现的自动互斥锁。现行规则是人工编排约束，不是已经部署的重复请求拦截程序。 |
| 历史证据与后来核验保持分离 | 私有子提示词标明证据用途；确切版本、截止日期、完整上下文及两个既有日期门槛逐项核对。取回材料分类如实保留，完整原文恢复和原主张对应需实际字节与独立复核支持。 | HTTP 200、下载完成、搜索命中数或文件体积，不能证明历史版本存在、原文完整、同一命题已被推翻，或案例已准入。 |
| 来源盲态与冻结试验保持完整 | 完整目标、查询、源文与后来答案只在来源人员私有记录；根任务、公共 STATE 和续跑提示词只收到安全状态、计数、标识与哈希。既有 Candidate 2 指导词、模型调用和评分冻结记录保持原始字节。 | 把知道后来结论的取件提示词直接作为历史模型指导词；事后修改冻结试验，或根据返回更换真假标签。 |

审计结论分开记录：**执行证据充分**、**发现具体偏差**、或**记录不足，无法证明**。来源盲态审阅者只能确认公开安全记录能支持的部分；私有查询/返回绑定由有权查看原件的独立审阅者核对，再返回不含来源身份和答案的检查结果与哈希。不能把未经检查的自述提升为验证通过。

报告至少区分：已登记轮次与尝试数、能够证明预先拆解的操作数、实际执行和失败数、预算及重复执行检查、真正恢复的完整原件数、独立准入数，以及是否发生模型测试。拆解动作真实执行可以验收，即使本轮没有找回原文；找回原文也不自动证明真假判断。软件测试、提示词变长、查询改写或成功 HTTP 状态均不计作真实新闻准确率提升。

本清单未读取私有来源、真实查询、原文或 gold，未发起网络/模型调用，也未执行上述实测。因此这里只给出验收标准，不预填本轮通过、来源恢复或准入结论。
