## 测了什么

两组使用同一 hosted `gpt-6-astra`、medium reasoning，通过本地 Codex 登录通道执行。这里“本地”指调用通道，模型推理仍在远端；没有切换到 API 备用通道。两组关闭已安装技能目录，使用相同的完整历史文本。

两道题来自两个事件家族，输入证据截止于 2023-12-31。错误案例的对应事实后来在 2025–2026 年被纠正，后来的材料只用于独立定标和评分，不进入模型输入。它是一个被纠正的具体事实，不能据此声称存在故意造假。模型自身的预训练记忆无法被这一证据截止设置清除。

这两道题已经用于上一轮发现错误，因此本轮明确属于 **已暴露的开发集**，不是新的保留测试集。历史输入、目标原文、标签和评分方法全部复用并核对哈希。每组都重新调用模型；四行固定顺序为第一题直接组/harness，第二题 harness/直接组，仅运行一次。

Candidate 3 在 Candidate 2 后加入 1,967 字符的通用要求，只作用于 harness 的分解和正式核验阶段：最终标签应对应原始目标，不能把“来源报道了 X”的成立转移给“X 实际发生”。同时保留充分的一手证据可直接支持事实的规则，不一律要求第二个来源。组合指导词共 5,872 字符，独立审计确认实际四次分解/核验输入的位置和全文均正确。

## 没成功的具体环节

实际答案仍把错误案例判为 supported。直接组仍把解释缩小到来源所述内容；harness 则把同一断言记录重新定性为足够的一手事实证据，并以同一文档内部一致、未发现反例加强说明。没有新增合格观察或推导补上原来的证据缺口。因此，标签与说明表面上一致，也可能只是说明变得更肯定，不能计为改善。

充分的一手记录本来就可能支持普通事实；问题在于，本轮没有提供足够依据证明被引用记录具备模型赋予它的证明力。找到最早来源、引文准确、同文一致、没有反例，都不能单独完成这个判断。真实对照仍被两组正确接受，没有观察到额外误伤。

独立语义审阅已完成：四个答案的最终引文都与来源一致，但只有真实对照的两个答案支持了实际事实目标。审阅核对了 22 个响应引用对象和 16 个正式证据片段。自动检查通过表示请求、引用身份、格式及流程有效；不表示四个最终结论都得到事实证据支持。

两次 harness 执行分别使用 5 和 8 次调用，各只执行一次正式分解和一次正式核验，未触发回访或第二轮分析。本轮不能声称双循环已实际执行。来源网络在隔离的模型工作进程中关闭，研究阶段处理的是提供的历史材料；本轮没有新发现或补回外部原始附件。

## 验证与复现范围

运行前 38 项离线软件检查通过，其中 19 项为独立检查。完整虚构响应测试包含四个结果、20 个固定响应调用；八个虚构语义对照的预期标签另经独立审阅。**这些离线检查和标签审阅不是八道题的真实模型语义测试。** 本轮真实模型测试的范围仍然只有上述两道题。

2026-09-09 19:13:13 UTC 登记并冻结协议、输入、标签、评分依赖和 25 项推理代码后才启动。全部 15 个实际请求先通过审计，评分器随后核对私有标签的原始字节哈希再解析。没有改变运行中的代码、标签或限制；所有四行都保留在分母内。

根任务的第一版审计摘要错误地以 `status == success` 统计成功数，写成 0；实际记录使用 `status == completed` 和 `success == true`。读取标签评分前另存了更正版，成功数为 15。原版保留。这个派生计数错误没有改变实际请求、独立审计、模型结果或评分代码。

这轮没有达到停止条件。Candidate 4 已形成待测提案，针对“把断言重新命名为已验证证据”，要求为赋予证据的证明力指出具体依据。它尚未实现、登记或调用模型。下一步先登记并运行充分一手证据与缺失必要依据的成对语义测试；如果旧指导词已经全部答对这些对照，就不能把天花板结果当作新方案有效的证据。任何开发集改善仍需在未用于选提示词的独立事件上确认；正确保留未解决状态也不能算作检出了后来确认的事实错误。
