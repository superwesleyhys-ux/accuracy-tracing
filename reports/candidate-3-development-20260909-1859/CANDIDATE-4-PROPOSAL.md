# Prospective Candidate 4: ground the claimed evidential role

Status: one source-blind, unimplemented hypothesis. No private source text, gold values, or model prose was read. No model call, registration, code change, or alteration of an existing trial is authorized by this document.

The parent relayed the independent semantic finding from Candidate 3: direct still narrowed the target to attribution; the harness instead described the same assertion as adequate first-hand factual evidence, cited agreement within the document and absence of a found counterexample, and retained supported. No new eligible observation or derivation closed the previously identified evidential gap. Thus a verdict/rationale consistency instruction can be satisfied by strengthening an unsupported description of the evidence. It can remove a visible inconsistency without repairing the underlying inference.

## One mechanism and its limit

Require each *stronger claimed evidential role* used to justify a real-world verdict to be grounded in a specific feature of eligible evidence. The intervention tests whether making this dependency explicit prevents an assertion from being renamed an observation, authenticated record, independent confirmation, or executed derivation without supporting material. It uses existing notes/qualifiers/rationale and canonical citations, within the existing check and call limits.

This is not a requirement for a second source. Ordinary adequate first-hand records can be positive evidence. A record can also constitute the target event rather than merely describe a different event. An explicit attribution target may be established directly. Valid derivations may settle a claim when their supplied premises, scope and operations are sufficient. An evidenced contradiction remains possible. The original source has priority for tracing wording and provenance, but original-source status is not proof of the underlying claim or authenticity of the observations.

There is a hard limit: text stating that its author observed something can establish that an observation is *claimed*. It does not by itself independently authenticate that observation. Conversely, lack of independent authentication does not make every ordinary first-hand record inadequate. The required evidential adequacy depends on the exact target. A plausible erroneous original and an accurate original may be indistinguishable in the eligible packet. If no distinguishing evidence is supplied, a prompt cannot recover unavailable later truth; abstention or a better-qualified explanation is not detection of that truth.

## Proposed literal suffix for review

Proposed placement: once after the frozen Candidate 3 guidance, only in harness decompose/verify instructions. Direct, research stages, schemas, verdict labels, evidence admission, source pool, and budgets remain unchanged. This is a prompt-only proposal; it does not install the following text.

```text
Ground any evidential role used to justify the target. If you call a passage an
observation, first-hand record, independently confirmed fact, or derivation,
identify the exact eligible text or record feature supporting that description.
State briefly what it establishes for the unchanged target. Do not obtain a
stronger role merely by renaming the assertion being evaluated.

Separate a source's claim to have observed or verified something from supplied
evidence independently authenticating that claim. Do not claim such independent
authentication unless eligible material establishes it. Original-source status
locates the origin of a statement; it does not prove the event described. Repeated
assertions, agreement within a document, and no counterexample found do not
supply a missing observation or independently establish authenticity. A valid
derivation requires the supplied premises and the actual applicable operation.

Preserve adequate ordinary first-hand evidence: a second source is not mandatory,
and a missing external record alone does not require unresolved or contradicted.
If the supplied record itself constitutes the exact target event, assess that
event rather than imposing an unrelated authentication target. Settle explicit
attribution when established. Use affirmative observation or derivation evidence
when it adequately supports the actual target and its scope.

If the stronger role needed by your justification lacks a cited basis, remove
that role claim and reassess the target using only the evidence that remains.
Do not fill the gap with confidence, reputation or consistency alone. Preserve
unresolved if a necessary step remains unsettled; contradict only on eligible
evidence excluding the target after the existing checks. Give the concise role,
cited basis and relevant limitation in existing fields, not new JSON keys or a
reasoning transcript. Stay within the existing check and call limits and retain
all preceding evidence, temporal and target-scope constraints.
```

The suffix makes no prediction of a gain. In particular, relabeling the same text as “a claimed first-hand record” must not become another route to asserting independent authentication. Reviewers must evaluate the decisive evidence-to-target inference, not reward the presence of these terms or longer explanations.

## Disconfirmation and progression

The mechanism is disconfirmed if Candidate 4 still upgrades an assertion without a cited basis, supplies a decorative citation that does not establish the claimed role, relies on agreement/no counterexample to fill the same gap, or simply rewrites its conclusion more confidently. It also fails its safeguards if adequate first-hand true records, attribution, constitutive events or valid derivations are downgraded without reason; if it requires independent corroboration universally; or if it converts missing evidence into false accusations. Lower false acceptance achieved solely by indiscriminate abstention is not an accuracy win. Passing fictional role tests without a grounded verdict benefit is at most a narrow mechanistic result.

Only if this preregistered fictional real-model test supports the mechanism should an explicitly exposed development rerun of the already used real pair be considered. That rerun cannot become a new holdout, even if source text is hidden from the prompt author. A justified move from supported to unresolved may improve a fixed unresolved cutoff score, but counts as abstention, not recognition of the later falsehood. Future-correct guesses lacking cutoff evidence do not count as grounded detection.

Any broader improvement claim then needs prospective confirmation on additional independent, previously unused event families. Freeze original-version evidence, target meaning, affirmative real-world true controls, independently established false labels, cutoff labels, exposure/admission records and scoring before inference. Keep errors distinct from fabrication or intent. Include enough variation in adequate evidence types to test the safeguard, not just additional bare-assertion cases. Preserve ties and regressions; do not select the next family after observing which evidence style the candidate handles.

If the prompt-only real-model test fails, do not automatically add another warning or rerun the same pair. A separate structured experiment may be warranted: an explicit evidence-role record bound to canonical spans, target scope, derivation inputs and dependencies, with host checks for references and a semantic evaluator for entailment. Span validation alone still cannot authenticate a claimed observation. Such a design changes schemas, responsibilities or scoring and requires a new proposal, tests, controls and registration; it is not part of this prompt-only endpoint.
