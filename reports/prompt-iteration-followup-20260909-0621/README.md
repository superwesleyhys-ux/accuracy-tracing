20 次操作包括 8 次搜索、5 次网页读取和 7 次直接请求。记录保留 4 次传输错误；另有 3 次请求虽然返回成功状态，仍未取得有效的目标原文。失败和未完成结果均保留，没有替换成其他例子或修改准入要求。

公告证据目前是检索服务返回的发布方文本，未取回发布方原始文件或底层分析材料。按截止日期筛选的搜索仍返回了后来和无关的内容，不能据此证明“此前没有公开证实”。独立复核确认暂不准入；55 个新文件条目、243 个旧文件、7 个旧清单及 5 个排除索引全部匹配，五项成功的派生结果可复现。

本轮同时实现了一个独立的计分部分，仅使用虚构输入验证。30 项实现检查和 8 项独立回归检查全部通过，覆盖以下问题：

- 真实新闻被判假必须计入误报，不能因为题目属于“真实性”就算造假检出。
- 后来确实为假的命题，仍需区分当时有证据的判断和碰巧猜对；无法判断不计检出。
- 研究步骤失败，即使最后的形式核验给出正确答案，也不能取得主要正确率得分。
- 整批执行中断时保留全部计划题目，但主要比较不可用；不能删掉失败题后重算。

独立反例中，harness 连续把两条新闻判假，命中一条假例、同时误判一条真例；未来真假命中数并未超过基线，按截止日期证据计分还更差。它检验的是计分规则，不是真实模型表现。
