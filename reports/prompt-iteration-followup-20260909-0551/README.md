# 机构附件溯源续查

**已取回机构判定理由，但仍缺对应的历史广告原件；本轮未新增合格假例，也未重跑模型。** 原有 Astra 与 harness 的准确率结果保持不变，尚未证明 harness 超过原始 Astra。token 优化仍暂停。

这轮承接上一轮定位的机构附件线索，只查同一个事件。事先限定最多 20 次查询、20 分钟，实际完成 20 次，耗时约 8 分 20 秒。

| 结果 | 数量与含义 |
|---|---|
| 机构判定理由 | 1 份；有助于明确被判定不实的具体命题 |
| 后来的示例广告图片 | 1 张；无法据此证明它就是截止日期前的原版 |
| 可核验的截止日期前目标广告原件 | 0 份 |
| 完整适用的事实附件 | 0 份 |
| 新增合格假例 | 0 个 |
| 已独立审核的真实事件对照 | 保留 1 个，尚未组成新真假测试组 |
| 新增基准模型调用 | 0 次 |

判定理由支持的是广告传达的“总价”命题不实，不能直接改写为每个印出的基础价格都不真实。仍需目标广告的完整版面、限定条件、活动日期及版本，才能把一个明确的历史命题与后来的事实认定准确对应。“何时首次公开证实这个具体命题不实”也仍需核验。后来公布的理由和图片不会作为 2024 年前的模型输入。

查询包括 5 次搜索、13 次直接请求、1 次文档文本读取和 1 次文档截图尝试。13 次直接请求中 6 次成功、7 次失败；截图尝试也失败。成功取得响应不等于取得所需原件。新查询保留了完整送达的返回内容、错误、每次起止时间和文件哈希；这些记录不声称覆盖服务内部不可见的活动，也没有补造上一轮缺失的历史记录。

独立复核确认上述“不准入”结论。68 个新文件条目和 175 个旧文件的哈希全部匹配；20 次操作的时间与记录相符。派生内容复现时，10 个导航链接仅有末尾空片段标记的差异，正文、图片引用和实质链接一致，原记录保留未改。

新测试接入准备同时完成了一份不接触题目内容的检查清单：新题可能只有一个合格来源版本，不应为了适配旧测试而复制成两个；真假混合题的计分必须依据真实标签分别统计检出与误报。这里只完成了改动定位和结构验证，**尚未修改运行器或计分器，也未启动新测试**。

当前已尝试且失败或为空的路径暂时停止重复查询。拿到具体原帖标识、可访问的适用附件副本，或此前不可用的普通浏览器恢复可用后，可以重新评估；这不代表所有可能来源都已穷尽。持续任务保持启用，下一轮转查未筛过的独立事件，保留严格的历史来源与真假标签要求；获得合格题组后，再完成新计分和隔离检查、登记并运行配对测试。
